# Roshan Akther — Professional Portfolio

A personal portfolio website built and deployed as part of the **System Analysis and Design (SAD)**
module at the University of Vavuniya. The site presents my education, technical skills, and projects,
and includes a downloadable CV — intended for use in internship and job applications.

🔗 **Live site:** https://roshan-dev-0725.github.io/portfolio/
🔗 **LinkedIn:** https://www.linkedin.com/in/roshan-akther-6a12b037b
🔗 **GitHub:** https://github.com/Roshan-Dev-0725

## Sections

- **Home** — introduction and navigation
- **About Me** — professional summary, interests, career objective
- **Education** — BICT degree, University of Vavuniya, coursework
- **Skills** — technical (Java, Python, C, C++, C#, web tools) and soft skills
- **Projects** — four projects with problem, contribution, tools used and links
- **Experience & Activities** — team and self-directed project work
- **CV** — view or download an up-to-date CV as PDF
- **Contact** — email, LinkedIn and GitHub

## Tech Stack

- HTML5, CSS3, JavaScript (vanilla, no framework)
- Single-file layout: all CSS and JS embedded in `index.html`
- Fonts: Sora, Inter, JetBrains Mono (Google Fonts)
- CV PDF generated with Python (ReportLab)

## Project Structure

```
portfolio/
├── index.html                     # full site (HTML + CSS + JS)
├── assets/
│   ├── Roshan_Akther_CV.pdf       # downloadable CV
│   └── avatar-placeholder.svg     # profile photo
└── README.md
```

## Running Locally

No build step required. Clone the repository and open `index.html` in any browser:

```bash
git clone https://github.com/Roshan-Dev-0725/portfolio.git
cd portfolio
open index.html   # or double-click the file
```

## Deployment

Hosted for free on **GitHub Pages** from the `main` branch, root folder.
